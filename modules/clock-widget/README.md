# Clock Widget

Native desktop card for the XFCE Tweaks host (ABI 1), licensed GPL-2.0-or-later.

Build independently with `python3 scripts/tweak-tool.py build modules/clock-widget` from the project root. Package/import through XFCE Tweaks Manager. Click to configure, drag to move, drag the bottom-right grip to resize. Appearance and content settings persist in Xfconf.

See `docs/CLOCK-WEATHER.md` in the project for service terms, privacy, dependencies, tests, and limitations. Shared support sources are exported by `scripts/sync-widget-sources.py`; packaged sources build without that script.
