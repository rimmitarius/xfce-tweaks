# CPU Monitor

Independent native desktop monitor card for XFCE Tweaks. It renders inside the xfdesktop icon view, stays behind normal windows, and remembers its position and size per display. Click to configure; drag to move between monitors; resize from the lower-right corner. It shares the theme, background image/color and opacity, border, corners, font scaling, text shadow and hover settings used by the other XFCE Tweaks widgets.

This module is read-only. Metrics come from Linux procfs/sysfs and, for NVIDIA, dynamically loaded NVML. Missing driver telemetry is shown as unavailable. The card samples once per second and stops sampling when disabled.
